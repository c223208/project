## 技術仕様

### 1. アプリケーション概要

不安障害などを抱える友人・同僚の少しでも力になりたいと願う人のためのノート。

アプリ化可能なWebサイトで、一般的なデジタルノートの機能に加え、症状・薬の作用/副作用を簡単にまとめることや、薬の種類/量や(主観による)精神状態の変化をカレンダー形式で記録することができる。
また、ホーム画面上のポップアップで、利用者の視野を広げ精神的に楽になるような声掛けを行う。

### 2. 開発環境および技術スタック

本アプリケーションは、主に以下のプログラミング言語とフレームワークで構成されている。Pythonが主要言語であり、WebアプリケーションのバックエンドをFlaskが担っている。

| 項目 | 詳細 |
| :--- | :--- |
| **主要言語** | **Python** (57.3%) |
| **Webフレームワーク** | **Flask**  |
| **フロントエンド言語** | **HTML** (42.7%) |
